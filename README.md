# Dina_landing_page

Official Modern Luxury White Editorial Landing Page for **Dr. Dina Lundy, Ph.D.** — Psychologist, Author, Professor & Child Welfare Advocate.

---

## 🌟 Overview
- **Visual Design**: Editorial pure white luxury aesthetic with 3D tactile elevation, layered depth, and gold/crimson accents.
- **Key Sections**:
  - Top Hero Banner & Famous Quote
  - Published Books releases with purchase and preview modals
  - Current Human Development Courses & Blueprint
  - Syllabus Support resource for educators
  - Featured Podcast: *You Are Not Going to Believe This* (with embedded YouTube player)
  - Trending Social Media Video Discussions (TikTok & YouTube Shorts with interactive video cards)
  - Recent Peer-Reviewed Publications & Google Scholar Archive
  - Social Media Hub (TikTok, Beacons, YouTube, Substack, LinkedIn, Instagram)
  - Academic Newsletter & Direct Contact Form
  - Schedule Meeting CTA (Calendly integration)

---

## 🚀 Quick Start (Development)
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Build for Production / Shared Hosting
```bash
# Compile and optimize production bundle into dist/
npm run build
```

To deploy to shared hosting (cPanel, Hostinger, Namecheap, etc.):
1. Run `npm run build`.
2. Upload the contents of the `dist/` folder directly to your hosting's `public_html` directory.
